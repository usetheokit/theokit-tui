## Cloned peers

### assistant-ui (`packages/react-ink`)
- **Repo:** https://github.com/assistant-ui/assistant-ui  · **License:** MIT (auto-approved-permissive)
- **Motivation:** The **direct analog** — AI-chat primitives already implemented in Ink.
- **What to study:** the "primitive" composition model, `MessagePartPrimitive`, `ComposerInput`,
  `ComposerQuote`, `AttachmentPrimitive`, `ToolFallback`, `StatusBarPrimitive`, `QueueItem`,
  `useTextBuffer`. Path: `packages/react-ink/src/`.
- **Supports:** M1 (chat), M2 (tool-use), M7 (stream adapter).

### ink
- **Repo:** https://github.com/vadimdemedes/ink  · **License:** MIT (auto-approved-permissive)
- **Motivation:** The Ink framework — React for the terminal. The foundation we build on.
- **What to study:** rendering model (`Box`/`Text`, Yoga flexbox), `useInput`/focus, `<Static>`,
  measurement/layout, `ink-testing-library`.
- **Supports:** M0 (foundation), M1 (viewport/input).

### ink-ui
- **Repo:** https://github.com/vadimdemedes/ink-ui  · **License:** MIT (auto-approved-permissive)
- **Motivation:** Official Ink component collection — reference for component-API design + theming in Ink.
- **What to study:** component prop API shape, theme context pattern, spinner/progress/badge structure.
- **Supports:** M0 (API conventions), M6 (theme system).

### gemini-cli
- **Repo:** https://github.com/google-gemini/gemini-cli  · **License:** Apache-2.0 (auto-approved-permissive)
- **Motivation:** A **production Ink coding-agent CLI** at scale — real streaming + tool-calls + theming.
- **What to study:** streaming render loop, tool-call display, theme system, terminal-robustness
  (NO_COLOR/resize), perf for large output.
- **Supports:** M1 (streaming), M4 (code/diff), M6 (theme/robustness).

### codex (`codex-rs/tui`)
- **Repo:** https://github.com/openai/codex  · **License:** Apache-2.0 (auto-approved-permissive)
- **Motivation:** High-craft agent TUI (Rust + `ratatui` + `crossterm`). Layout/interaction patterns
  transcend the language.
- **What to study:** diff rendering layout, streaming/scrollback, tool-output framing, keybindings,
  bracketed-paste. Path: `codex-rs/tui/`.
- **Supports:** M2 (tool-output), M4 (diff render).

### bubbletea
- **Repo:** https://github.com/charmbracelet/bubbletea  · **License:** MIT (auto-approved-permissive)
- **Motivation:** Gold-standard TUI framework (Go) — the Elm-architecture reference for TUI state/update/view.
- **What to study:** Model-Update-View loop, message passing, component-owned state, resize handling. Conceptual (Go).
- **Supports:** M0 (architecture), M6 (state/robustness).

### bubbles
- **Repo:** https://github.com/charmbracelet/bubbles  · **License:** MIT (auto-approved-permissive)
- **Motivation:** Gold-standard TUI **component set** (Go, companion to bubbletea) — well-designed TUI component APIs.
- **What to study:** viewport scrolling, progress/spinner design, textinput/textarea ergonomics, pagination.
- **Supports:** M1 (viewport/input), M5 (metrics: progress/gauge).
