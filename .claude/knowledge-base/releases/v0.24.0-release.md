## Summary

Ships the agent-decision vocabulary: ApprovalPrompt (children-slot preview +
once/always/reject), QuestionPrompt (SelectList options + optional "Other…"
free-text), PlanApproval (markdown body + approve/revise), backed by a new
`ChoiceRow` primitive + pure `agent-decision-model` and a shared `FreeTextInput`.
Callback-only (no app state machine), composition-first (zero prop-forwarding —
the DiffViewer/SelectList/MarkdownText are composed as children). A node-pty e2e
drives one full approve flow over the real raw-mode path through the V4 renderer.
