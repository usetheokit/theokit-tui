## Scope

- `ChatComposer` `bordered` prop (rounded box, Claude Code look; `single` under monochrome).
- Alt+Enter inserts a newline in multi-line mode (Enter still submits).
- `@`-mention **path navigation** (Claude Code parity): `@` + a path (`/` or `~`) lists that
  directory (`~` → `$HOME`), dirs-first, filtered by the trailing partial; directory
  selection keeps the `@` and continues navigating; file selection completes the mention.
  New pure exports: `isPathQuery`, `splitMentionPath`.
- Fixed: spurious leading `/` on file-mention rows (`SlashMenu.sigil`, default `/`, `""` for mentions).
