## Summary

Ships the live-turn progress vocabulary: TodoList (keyed replace-item), MultiStepProgress
(n-of-m + subagent variant, reusing the TodoList row), CollapsibleBlock/ThinkingBlock
(controlled/uncontrolled key-toggle), Toast (bounded one-shot timer) + notify()
(conservative OSC-9/BEL), and AgentStreaming phrase-cycler/shimmer opt-ins. The M12
reduced-motion gate was extracted to a shared `isMotionEnabled` predicate. Every timer
path is fake-timer tested; the OSC-9 matrix is proven end-to-end via the piped example.
