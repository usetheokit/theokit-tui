## GREEN

- `src/renderer/render-node.ts` — Ink's render-node-to-output.js + render-border.js
  + get-max-width.js ported, reduced to the M18 surface (NO clips/accessibility/
  static — unused). `renderNodeToOutput` walks the laid-out tree writing each node
  at `offset + getComputedLeft/Top`; text nodes squash + wrap-if-over-maxWidth;
  boxes draw borders (`cli-boxes` glyphs + `colorizeForeground` fg colors) then
  recurse. `applyPaddingToText` was dropped as a provable no-op (text children are
  always virtual — no yoga node).
- `renderer.ts` paint **rewritten**: `setWidth(terminal.columns)` →
  `calculateLayout` (height auto) → `new Output({computedW, computedH})` →
  `renderNodeToOutput` → `engine.render(output.get().output.split("\n"))`. The M17
  `assembleLines`/`textContent` are **deleted**; root yoga node freed on unmount.
- The 12 M17 renderer tests stay green under the new yoga paint (the parity scene,
  row/column, coalescing all still hold) — proof the yoga layout reproduces the
  old output where it was already correct.
