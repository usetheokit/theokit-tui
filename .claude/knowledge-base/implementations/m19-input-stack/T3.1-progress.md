## node-pty build note

node-pty 1.1.0's prebuilt binary is absent for this platform/node; built from
source via `node-gyp rebuild` (toolchain present: python3/make/g++). On a fresh
checkout without the build, the PTY tier SKIPs (EC-7) and the fake-stdin tier
gates.
