- **D1 union purity** — `src/agent-event.ts` is render-free: `import type` only (ChatRole/ToolCallStatus/ShellEnvelope), zero runtime ink/React imports; `AGENT_EVENT_KINDS` single-sources type + guard + error message.
- **D8 completeness** — `assertValidEvents` covers every documented check: kind membership, id uniqueness (empty-string legal), role ∈ CHAT_ROLES, status ∈ TOOL_CALL_STATUSES, output⊕shell exclusivity, plus the SEPA-F1 `maxLines` guard (beyond D8's documented scope, justified in-comment as mirroring ToolResult's mid-render guard). Docstring scope note (primitive types = TS's job) honest.
- **SRP** — agent-event.ts (types), agent-timeline.tsx (one surface: validate + dispatch + window), agent-streaming.tsx (indicator + co-located pure `formatElapsed`); all ≤ 207 LoC.
- **ISP** — 3 props each on `AgentTimelineProps` / `AgentStreamingProps`; no fat interfaces.
- **DIP** — theme reached exclusively via `useTheoTheme()` (ThinkingRow, AgentStreaming); ToolRow delegates to M2 components; no `defaultTheme` reach-around.
- **Composition-root discipline** — `formatElapsed` NOT on the entry (export-surface asserts absence); `unionMessage`/`KIND_UNION_MESSAGE`/`singleLine` module-internal; `STATUS_INDICATOR_WIDTH` module-level only (absence asserted); example + bench import via `../src/index.js`.
- **Coupling M3→M0/M1/M2** — strictly additive: `chat-thread.tsx`/`tool-result.tsx` untouched; chat-message/tool-call changes are const-array retrofits with types derived from them (no behavior change; existing tests green).

- **Guard-before-hooks** — `assertValidEvents(events)` is AgentTimeline's first statement (before `useMemo`); `formatElapsed` validation precedes `useTheoTheme()` in AgentStreaming; D3 switch `default` carries compile-time `never` + scoped `/* v8 ignore */` with the D8-screens-first justification.
