# Concepts

The load-bearing ideas the milestone reports assume without re-explaining.

- [Differential renderer](/concepts/differential-renderer.md) — the CSI-2026 engine
  that rewrites only changed rows, and the byte-cost argument for its existence.
- [Ink parity gate](/concepts/ink-parity-gate.md) — the dual-render method that
  proves our renderer shows what Ink shows.
- [Exit-gate triple](/concepts/exit-gate-triple.md) — component ∧ oracle set ∧
  example, the bar a parity row must clear to be graded ✓.
